# verify

아래 4개를 **순서대로, 각각 따로** 실행한다. 하나가 실패해도 나머지를 마저 돌려서 전체 그림을 보고한다.

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

## 보고 형식

| 단계 | 결과 | 비고 |
|---|---|---|
| typecheck | ✅ / ❌ | 에러 수, 첫 에러 위치 |
| lint | ✅ / ❌ | 경고/에러 수 |
| test | ✅ / ❌ | 통과/실패 개수 |
| build | ✅ / ❌ | 번들 크기 |

## 실패 시

- 원인을 진단하고 수정안을 제시한다. 요구사항 해석 차이가 원인이면 수정하지 말고 사용자에게 묻는다.
- 수정했으면 다시 `/verify`. **모두 ✅가 될 때까지 다음 단위로 넘어가지 않는다.**
- 테스트가 0개인 단위는 "테스트 없음"을 명시하고, 핵심 로직이 포함된 단위라면 테스트 추가를 제안한다.
